# Checklist Discipline Skill

## Rules
- Treat `.codex/plans/project-checklist.md` as the canonical milestone tracker.
- Move substantial work into `In Progress` before implementation.
- Move milestones into `Completed` only after local verification succeeds.
- Keep `Next` focused on the immediate follow-up milestone.
- Use `Possible Later` for non-essential ideas so scope stays classroom-sized.
