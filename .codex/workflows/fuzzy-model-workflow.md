# Fuzzy Model Workflow

1. Update the checklist item before changing fuzzy logic behavior.
2. Review `docs/fuzzy-system-design.md`.
3. Check whether the change still fits UAE year-round calibration.
4. Keep membership sets compact and explainable.
5. Add or adjust tests for directional behavior.
6. Update explanation text if the user-facing interpretation changed.
7. Mark the checklist item complete only after tests pass.
