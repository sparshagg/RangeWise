# Fuzzy Model Workflow

## Goal
Keep the fuzzy and hybrid range model explainable and testable.

## Steps
1. Update `.codex/plans/project-checklist.md`.
2. Adjust dataset-backed `Shown Range` logic only if the grouped-efficiency story changes.
3. Adjust fuzzy membership functions and rules with UAE labels and full coverage in mind.
4. If ANFIS behavior changes, document whether retraining is required and why.
5. Update tests for directional behavior, fallback behavior, and output coverage.
6. Update README and design docs if the public model story changed.
